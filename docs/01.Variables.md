# 01. Variables

[Course index](README.md) · [Previous](00.DataTypes.md) · [Next](02.TypeConversionAndCasting.md)

A variable is a named place for a value. Declare its type and name, then use `=` to assign a value:

```csharp
int score = 10;
score = 15;
score += 5; // Same result as score = score + 5.
score++;    // Add one.

const int winningScore = 100;
Console.WriteLine($"Score: {score}/{winningScore}"); // Score: 21/100
```

Declaration introduces the name. Initialization gives it a first value. Assignment changes the value later. A `const` is fixed at declaration and must use a compile-time constant value.

Use descriptive names such as `playerName` or `remainingLives`. C# names are case-sensitive: `score` and `Score` are different names.

A local variable must be assigned before you read it:

```csharp
int lives;
// Console.WriteLine(lives); // Compile error: not assigned yet.
lives = 3;
Console.WriteLine(lives);
```

A variable declared inside `{}` normally belongs to that block's scope. You cannot use it after leaving the block. Later lessons explain fields, which belong to objects (or to a type when static) rather than a method's local scope.

## Practice

Start with three lives, subtract one, and print the remaining lives. Declare a constant for the maximum number of lives.

# Creating Objects

[Course index](README.md) · [Previous](16.Records.md) · [Next](18.TargetTypedNew.md)

Here we create class instances; objects can also be instances of other types, such as structs. Use `new` to create one. A constructor runs when the object is created.

```csharp
var player = new Player("Ari");
Console.WriteLine(player.Name);

public class Player
{
    public Player(string name) => Name = name;

    public string Name { get; }
}
```

Using the `Player` class above, there are three common ways to declare a variable and create an object:

```csharp
Player first = new Player("Ari");
Player second = new("Bea");
var third = new Player("Cam");
```

All three variables are strongly typed as `Player`. The difference is only how much type information you write.

Use an object initializer when you create an object with settable properties:

```csharp
var genre = new Genre { Id = "rpg", Name = "RPG" };

public class Genre
{
    public string Id { get; set; } = string.Empty;
    public string Name { get; set; } = string.Empty;
}
```

Choose the form that makes the type and required data easy to understand.

## Try it

Create a `Player` using its constructor, then create a `Genre` with an object initializer.

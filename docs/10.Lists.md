# 10. Collections with `List<T>`

[Course index](README.md) · [Previous](09.NullableTypes.md) · [Next](11.Classes.md)

A collection holds several values. Use `List<T>` when you need an ordered group of items that can grow or shrink. `T` means the type of every item in the list.

```csharp
List<string> names = new()
{
    "Alice",
    "Bob"
};

names.Add("Anna");
Console.WriteLine(names[0]); // Alice
```

`List<string>` accepts only strings. This is useful because the compiler can catch mistakes such as adding a number to the list.

Modern C# also supports a collection expression. The type on the left tells the compiler what collection to create:

```csharp
List<string> names = ["Alice", "Bob", "Anna"];
```

Use a list when the number of items can change. An array's length is fixed, although its elements can still be changed.

```csharp
List<string> games = ["Hades", "Celeste"];
games.Add("Portal");
games[0] = "Hades II";
games.Remove("Celeste");

Console.WriteLine(games.Count);             // 2
Console.WriteLine(games.Contains("Portal")); // True

foreach (string game in games)
{
    Console.WriteLine(game);
}
```

`Count` is the number of items. Indexes range from `0` to `Count - 1`; an index outside that range throws. Avoid adding or removing items from a list during a `foreach` over it.

`T` is a generic type parameter. You can use the same list structure with another element type, for example `List<int>` or `List<Game>`. Square-bracket collection expressions require C# 12 or later; this project's .NET 10 setup supports them.

## Try it

Create a `List<int>` with three game prices, add one more price, then print the number of items with `Count`.

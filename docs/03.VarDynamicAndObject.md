# 03. `var`, `dynamic`, and `object`

[Course index](README.md) · [Previous](02.TypeConversionAndCasting.md) · [Next](04.IfElse.md)

`var` asks the compiler to infer a local variable's type from its first value. The variable stays strongly typed.

```csharp
var score = 10;       // The compiler knows score is int.
// score = "ten";    // Does not compile.
```

`object` (`System.Object`) is the common base type for the ordinary value and reference types used in this course. Some specialized types, such as `ref struct` types, cannot be stored in an `object` variable. An `object` variable can hold different kinds of values, but the compiler treats it as `object` until you check or cast it.

```csharp
object value = 10;

if (value is int score)
{
    Console.WriteLine(score + 1);
}
```

`dynamic` delays checking member operations until runtime:

```csharp
dynamic message = "hello";
Console.WriteLine(message.ToUpper()); // HELLO
message = 10;
// message.ToUpper(); // Compiles, but throws if executed: int has no ToUpper.
```

| Form | What C# knows | Member access |
| --- | --- | --- |
| `var score = 10` | The variable is `int` | Checked as `int` at compile time |
| `object score = 10` | The variable is `object` | Check or cast before using int-specific operations |
| `dynamic score = 10` | Member operations are resolved later | Checked at runtime; errors can become exceptions |

`var` is type inference, not a separate runtime type. It needs an initializer and cannot infer a type from `null` alone. An `object` or `dynamic` variable can later hold a different kind of value.

Prefer explicit types or `var` for everyday application code. Use `object` for a deliberately general API, and `dynamic` when an integration requires runtime binding. Storing an `int` in `object` boxes its value; casting it back to `int` unboxes it.

## Try it

Declare the same string with `var`, `object`, and `dynamic`. Try calling `ToUpper()` on each. Check the `object` value with `is string text` first. Explain which errors occur at compile time and which occur at runtime.

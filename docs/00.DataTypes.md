# 00. Data Types

[Course index](README.md) · [Next](01.Variables.md)

A type tells C# what kind of value you have and which operations are allowed. Start with these common types:

| Type | Stores | Example |
| --- | --- | --- |
| `int` | Whole numbers | `12` |
| `long` | Larger whole numbers | `3_000_000_000L` |
| `double` | Numbers with fractions, using binary floating point | `3.14` |
| `float` | Binary floating point with less precision than `double` | `3.14f` |
| `decimal` | Decimal numbers, commonly used for money | `29.99m` |
| `bool` | True or false | `true` |
| `char` | One UTF-16 code unit | `'A'` |
| `string` | Text | `"Hades"` |

The suffix `m` makes a numeric literal a `decimal`; without it, `29.99` is a `double`. Use single quotes for `char` and double quotes for `string`.

```csharp
string title = "Hades";
int stock = 3;
decimal price = 29.99m;
bool available = stock > 0;

Console.WriteLine($"{title}: {price}, available: {available}");
```

`$"..."` is string interpolation: expressions inside `{}` become part of the text.

Value types, such as `int`, copy their values when assigned. Reference types, such as classes, copy a reference to an object. We will explore that distinction in the classes lesson. `string` is also a reference type, but its text is immutable: operations such as concatenation produce a result rather than changing the existing string. `int` and `System.Int32` name the same .NET type.

With integer operands, `/` performs integer division: `5 / 2` is `2`, while `5.0 / 2` is `2.5`. Numeric types have finite ranges and precision; `decimal` is not unlimited precision.

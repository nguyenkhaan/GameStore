# Static Classes

[Course index](README.md) · [Previous](22.AnonymousTypes.md) · [Next](24.ExtensionMethods.md)

A static class groups members you use without creating an object. You cannot create an instance of it with `new`.

```csharp
decimal total = GameRules.ApplyTax(10m);
Console.WriteLine(total); // 11.0

public static class GameRules
{
    public static decimal ApplyTax(decimal price) => price * 1.1m;
}
```

Methods, fields, and properties in a static class must be static. Constants are implicitly static, and nested type declarations are also allowed. Access static methods through the class name, as in `GameRules.ApplyTax(10m)`.

Use a static class for grouped helper methods that do not need object-specific data. `Math` is a familiar example: you call `Math.Round(...)` without creating a `Math` object.

A regular class can also have static members. A static member belongs to the type rather than an individual instance; a static field holds one value per type.

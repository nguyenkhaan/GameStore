# `readonly` Fields

[Course index](README.md) · [Previous](24.ExtensionMethods.md)

An instance `readonly` field can be assigned when it is declared or directly inside an instance constructor of the class that declares it. After construction, that field cannot be assigned again.

```csharp
public class GameSession
{
    private readonly DateTime _startedAt;

    public GameSession()
    {
        _startedAt = DateTime.UtcNow;
    }
}
```

This does not make the referenced object immutable. For a reference-type field, it only prevents the field from pointing to a different object after construction. The following members belong inside a class:

```csharp
private readonly List<string> _players = [];

public void AddPlayer()
{
    // _players = [];       // Does not compile here.
    _players.Add("Alice");  // Allowed: the list itself remains mutable.
}
```

Use `readonly` for a dependency or value that should remain attached to the object after it is created. A `const` needs a compile-time constant, whereas a `readonly` field can receive a runtime value. A `static readonly` field is initialized at its declaration or in the type's static constructor.

For properties that should only be assigned during object creation, use `init`. The `readonly` field modifier does not apply to ordinary class properties. You may encounter other uses of `readonly`, such as readonly structs or struct members; those are separate language features.

# 08. `Func`, `Action`, and Delegates

[Course index](README.md) · [Previous](07.LambdasAndExpressionBodies.md) · [Next](09.NullableTypes.md)

A delegate type describes a callable signature: its parameters and return type. A delegate instance refers to one or more methods, including the target object for each instance method. You can assign a compatible named method or lambda to a delegate variable.

`Func` is the usual delegate when a method returns a value. Its final type argument is the return type:

```csharp
Func<int, int, int> add = (left, right) => left + right;
Console.WriteLine(add(3, 4)); // 7
```

This `Func` accepts two `int` values and returns an `int`. Use `Action` for a method that returns no value:

```csharp
Action<string> showMessage = message => Console.WriteLine(message);
```

You can create a named delegate type when it makes the code clearer:

```csharp
DiscountCalculator halfPrice = price => price / 2;
Console.WriteLine(halfPrice(20m)); // 10

public delegate decimal DiscountCalculator(decimal price);
```

A named method can also be assigned to a matching delegate:

```csharp
int Add(int left, int right) => left + right;

Func<int, int, int> operation = Add;
Console.WriteLine(operation(3, 4)); // 7
```

Assign `Add`, not `Add(3, 4)`: the first refers to the method, while the second calls it and produces an integer. `Func<TResult>` has no inputs and returns a value. Plain `Action` has no inputs and returns `void`.

Here is how to pass behavior into another function:

```csharp
int Calculate(int left, int right, Func<int, int, int> operation)
{
    return operation(left, right);
}

Console.WriteLine(Calculate(8, 3, (left, right) => left - right)); // 5
```

Delegates are useful for callbacks and for passing a piece of behavior into another method.

# 13. Constructors and Primary Constructors

[Course index](README.md) · [Previous](12.FieldsAndProperties.md) · [Next](14.Interfaces.md)

A constructor initializes a new object. It has the class name and no return type, not even `void`.

```csharp
var player = new Player("Alice");
Console.WriteLine(player.Name); // Alice

public class Player
{
    public Player(string name)
    {
        Name = name;
    }

    public string Name { get; }
}
```

The caller supplies `name`, and the constructor assigns the property. A non-static class without an instance constructor gets a parameterless constructor automatically, provided an accessible parameterless base constructor exists. It is public for an ordinary class and protected for an abstract class. Once you declare a constructor, that automatic constructor is no longer supplied.

## Primary constructors

C# 12 introduced primary constructors for classes and structs. Put the parameters after the class name:

```csharp
var player = new Player("Alice");
Console.WriteLine(player.Name);

public class Player(string name)
{
    public string Name { get; } = name;
}
```

These parameters are available inside the class, but they do **not** automatically become public properties. We explicitly declared `Name`. Positional records behave differently, as the records lesson explains.

You can add another constructor by chaining to the primary one:

```csharp
public class Player(string name)
{
    public Player() : this("Guest") { }

    public string Name { get; } = name;
}
```

Use an ordinary constructor when several initialization steps need a clear body. A primary constructor can shorten straightforward initialization.

## Practice

Write a `Game` class whose constructor requires a name and price. Then rewrite it with a primary constructor and explicit properties.

# 04. If, Else If, and Else

[Course index](README.md) · [Previous](03.VarDynamicAndObject.md) · [Next](05.Loops.md)

An `if` statement runs code only when a condition is `true`. `else if` tests another condition, and `else` handles everything that remains.

```csharp
int score = 75;

if (score >= 90)
{
    Console.WriteLine("Gold");
}
else if (score >= 60)
{
    Console.WriteLine("Silver");
}
else
{
    Console.WriteLine("Keep practicing");
}
```

This prints `Silver`. An `if`/`else if` chain runs only the first matching branch, so put more specific conditions first.

| Operator | Meaning |
| --- | --- |
| `==`, `!=` | Equal, not equal |
| `>`, `<`, `>=`, `<=` | Compare values |
| `&&` | Both conditions are true |
| `||` | At least one condition is true |
| `!` | Reverse a Boolean value |

`=` assigns; `==` compares. A condition must be a `bool`, so C# does not accept `if (score)`.

```csharp
bool hasTicket = true;
int age = 20;

if (hasTicket && age >= 18)
{
    Console.WriteLine("You can enter");
}
```

`&&` stops when its left side is false, and `||` stops when its left side is true. This is called short-circuit evaluation.

## Practice

Print `Free`, `Affordable`, or `Expensive` for prices of zero, up to 30, or above 30. Try every branch.

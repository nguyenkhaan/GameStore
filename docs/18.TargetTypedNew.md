# Target-Typed `new`

[Course index](README.md) · [Previous](17.CreatingObjects.md) · [Next](19.ObjectInitializers.md)

Normally, `new` includes the type that you want to create:

```csharp
List<string> names = new List<string> { "Alice", "Bob" };
```

When the compiler already knows the type from the left side, you can omit the repeated type name:

```csharp
List<string> names = new() { "Alice", "Bob" };
```

This is called target-typed `new`. The target is `List<string>`, the type expected in that position.

You cannot use `var` with target-typed `new`, because there is no type for the compiler to infer:

```csharp
// Does not compile:
// var game = new();

var names = new List<string>(); // Works
```

Use target-typed `new` when it makes code shorter without hiding an important type.

## Try it

Rewrite `List<string> names = new List<string>();` using target-typed `new`.

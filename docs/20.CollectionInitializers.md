# Collection Initializers

[Course index](README.md) · [Previous](19.ObjectInitializers.md) · [Next](21.PatternMatching.md)

A collection initializer creates a collection and adds its first items in one expression.

```csharp
var names = new List<string>
{
    "Alice",
    "Bob",
    "Anna"
};
```

For `List<T>`, this calls `Add` for each item:

```csharp
var names = new List<string>();
names.Add("Alice");
names.Add("Bob");
names.Add("Anna");
```

Do not confuse this with an object initializer. A collection initializer supplies items to a collection; an object initializer assigns named members.

In current C#, the shorter collection-expression form is also available:

```csharp
List<string> names = ["Alice", "Bob", "Anna"];
```

Unlike the `{}` collection initializer, a `[]` collection expression needs a target collection type: `var names = ["Alice", "Bob"];` does not compile. Collection expressions can also create arrays; they do not always mean a list.

## Try it

Make a list containing three genre names, then loop through it with `foreach` and print each name.

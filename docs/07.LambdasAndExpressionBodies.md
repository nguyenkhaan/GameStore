# 07. Lambdas and Expression-Bodied Functions

[Course index](README.md) · [Previous](06.Methods.md) · [Next](08.FuncActionAndDelegates.md)

You may know the phrase “arrow function” from JavaScript. C# uses `=>` for lambda expressions and for expression-bodied members or local functions. They look similar but have different roles.

## A shorter named function

```csharp
int DoubleNumber(int number) => number * 2;
Console.WriteLine(DoubleNumber(3)); // 6
```

This named local function has the same result as a function with `{ return number * 2; }`. The expression body omits braces and the `return` keyword.

## An unnamed function

A lambda expression is a small unnamed function. It uses `=>`, read as “goes to.”

```csharp
Func<int, int> doubleNumber = number => number * 2;
Console.WriteLine(doubleNumber(3)); // 6
```

`Func<int, int>` describes one integer input and one integer output. The [next lesson](08.FuncActionAndDelegates.md) explains these delegate types.

The values on the left are parameters. The code on the right is the function body. Use braces when the body needs more than one statement:

```csharp
Func<int, int> doubleNumber = number =>
{
    Console.WriteLine($"Doubling {number}");
    return number * 2;
};
```

Lambdas are often passed to LINQ methods that work with sequences: `Where` filters items using a Boolean test, and `Select` transforms each item. For example:

```csharp
int[] numbers = [1, 2, 3, 4];
var evenNumbers = numbers.Where(number => number % 2 == 0);
```

Use `()` for no parameters and parentheses for multiple parameters: `() => 42` or `(left, right) => left + right`. A lambda with a braced body uses `return` if it needs to return a value. It can also read variables from its surrounding scope, called capturing variables.

# 11. Classes and Objects

[Course index](README.md) · [Previous](10.Lists.md) · [Next](12.FieldsAndProperties.md)

A class describes a kind of object. It groups data and behavior. An object is one instance created from that class.

```csharp
Player alice = new Player();
alice.Name = "Alice";
alice.AddScore(10);
Console.WriteLine($"{alice.Name}: {alice.Score}"); // Alice: 10

public class Player
{
    public string Name { get; set; } = string.Empty;
    public int Score { get; private set; }

    public void AddScore(int points)
    {
        Score += points;
    }
}
```

`Name` and `Score` are properties. `AddScore` is a method. `public` allows callers to access a member. `private set` lets the class change the score while callers can only read it. This is a simple example of encapsulation: controlling access to an object's data.

Classes are reference types. Assigning an object variable copies the reference, not the whole object. Continue the example above by placing these statements before the `Player` declaration:

```csharp
Player samePlayer = alice;
samePlayer.Name = "Alicia";
Console.WriteLine(alice.Name); // Alicia: both variables refer to one object.
```

Creating another object with `new Player()` gives it separate data. Later lessons explain constructors, interfaces, and inheritance.

## Practice

Create two players with different names and scores. Change one player's score and confirm that the other's score stays the same.

# Anonymous Types

[Course index](README.md) · [Previous](21.PatternMatching.md) · [Next](23.StaticClasses.md)

An anonymous type is a compiler-generated class whose name you cannot write in your source code.

```csharp
var person = new
{
    Name = "Alice",
    Age = 20
};

Console.WriteLine(person.Name);
```

Use `var` because you cannot write the compiler-generated type name yourself. The properties are read-only after creation:

```csharp
// person.Name = "Bob"; // Does not compile
```

Anonymous types are useful for small, local results, especially when selecting a few values in a LINQ query. Create a named class, record, or DTO when the data needs to move between methods, files, or API layers.

## Try it

Create an anonymous object with `Title` and `Price`, then print both properties.

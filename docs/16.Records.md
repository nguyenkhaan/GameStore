# 16. Records: Types for Data

[Course index](README.md) · [Previous](15.Inheritance.md) · [Next](17.CreatingObjects.md)

A record is a type designed for data. It generates useful behavior such as value equality and a readable `ToString()` result.

```csharp
var first = new GameInfo("Hades", 29.99m);
var second = new GameInfo("Hades", 29.99m);

Console.WriteLine(first == second); // True: matching values.
Console.WriteLine(first);          // GameInfo { Name = Hades, Price = 29.99 }

var discounted = first with { Price = 19.99m };
Console.WriteLine(first.Price);      // 29.99: original unchanged.
Console.WriteLine(discounted.Price); // 19.99

public record GameInfo(string Name, decimal Price);
```

This positional declaration generates a constructor and public `init` properties. `record` here means `record class`, which is a reference type. A plain class normally compares object identity; a record compares its runtime type and stored data. For collection members, equality follows the collection's own equality rules rather than automatically comparing every element.

`with` creates a shallow copy with selected changes. Referenced objects can still be shared between the copies.

Records are not always immutable. You can declare mutable properties with `set`:

```csharp
public record MutableGame
{
    public string Name { get; set; } = string.Empty;
}
```

Use records for data results or DTOs when value equality is useful. `record struct` is another option with value-type assignment semantics. Start with `record class` until you need that difference.

## Practice

Create a `PlayerInfo` record with a name and score. Compare two equal instances, then use `with` to make an updated score.

# 05. Loops

[Course index](README.md) · [Previous](04.IfElse.md) · [Next](06.Methods.md)

Loops repeat code. Use `for` when you need a counter:

```csharp
for (int round = 1; round <= 3; round++)
{
    Console.WriteLine($"Round {round}");
}
```

The parts are initialization (`round = 1`), condition (`round <= 3`), and update (`round++`). This prints rounds 1, 2, and 3.

Use `while` when repetition depends on a condition:

```csharp
int lives = 3;

while (lives > 0)
{
    Console.WriteLine($"Lives: {lives}");
    lives--;
}
```

A `while` can run zero times. A `do`/`while` checks after the body, so it runs at least once:

```csharp
int attempts = 0;
do
{
    attempts++;
}
while (attempts < 2);
Console.WriteLine(attempts); // 2
```

Use `foreach` to visit each item in a sequence:

```csharp
string[] games = ["Hades", "Celeste"];

foreach (string game in games)
{
    Console.WriteLine(game);
}
```

`break` leaves the nearest loop. `continue` skips the remaining body for that iteration. Ensure the condition can become false, or your loop may never end. Array and list indexes start at zero, so use `< Count` or `< Length`, not `<=`.

# Fields and Properties

[Course index](README.md) · [Previous](11.Classes.md) · [Next](13.Constructors.md)

A field is a variable declared directly in a class or struct. A property is a member that looks like a field to callers but uses accessors such as `get`, `set`, or `init` to read or assign a value. It may compute a value instead of storing one.

```csharp
public class Game
{
    private decimal _price; // Field: stores data.

    public decimal Price    // Property: controls access to data.
    {
        get => _price;
        set
        {
            if (value < 0)
            {
                throw new ArgumentOutOfRangeException(nameof(value));
            }

            _price = value;
        }
    }
}
```

An auto-property is the short form when no custom logic is needed:

```csharp
public string Name { get; set; } = string.Empty;
```

Prefer private fields and public properties for data that other code reads or changes. A property gives you a place to add validation later without changing how callers use it.

For an auto-property, the compiler generates a hidden backing field and accessors. You still use `game.Name`, not a method named `getName()` or `setName()`.

Properties can also be read-only (`get` only) or settable only during initialization (`get; init;`). A get-only auto-property can be assigned in its declaration or the containing type's constructor. Properties do not always need a getter; a custom set-only property is allowed, though uncommon.

Create a `Title` auto-property. Then create an `Age` property that refuses values below zero.

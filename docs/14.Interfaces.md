# 14. Interfaces

[Course index](README.md) · [Previous](13.Constructors.md) · [Next](15.Inheritance.md)

An interface describes a capability: the members a type must provide. Different classes can implement the same interface in different ways.

```csharp
IDescribable game = new Game("Hades");
Console.WriteLine(game.Describe()); // Game: Hades

public interface IDescribable
{
    string Describe();
}

public class Game(string name) : IDescribable
{
    public string Describe()
    {
        return $"Game: {name}";
    }
}
```

The `:` after the class declaration says that `Game` implements `IDescribable`. The method is public so callers can use it through the interface.

An `IDescribable` variable can refer to any implementing object. This lets a method depend on a capability without requiring one specific class. However, through that variable, you can directly use only the members exposed by the interface.

You cannot create an interface with `new IDescribable()`. Create an implementing class instead. A class can implement multiple interfaces. The `I` prefix is a naming convention, not a compiler requirement.

Modern interfaces can include default implementations, but start with simple contracts like this one.

Create `IPlayable` with a `void Play()` method. Implement it in two classes, then call each through an `IPlayable` variable.

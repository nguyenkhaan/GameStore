# 09. Nullable Variables

[Course index](README.md) · [Previous](08.FuncActionAndDelegates.md) · [Next](10.Lists.md)

`null` means no value is present. It is different from `0`, `false`, or an empty string.

An ordinary `int` cannot hold `null`. Add `?` for a nullable value type:

```csharp
int? score = null;
Console.WriteLine(score ?? 0); // 0: use a fallback when score is null.

score = 10;
if (score.HasValue)
{
    Console.WriteLine(score.Value); // 10
}
```

Reading `.Value` when there is no value throws an exception. Check first or use `??`.

For reference types, `string?` tells the compiler a reference may be null. With nullable analysis enabled, `string` communicates that it should not be null. These annotations produce warnings; they do not add runtime protection.

```csharp
string? nickname = null;
Console.WriteLine(nickname?.ToUpper() ?? "Guest"); // Guest

if (nickname is not null)
{
    Console.WriteLine(nickname.Length);
}
```

`?.` skips member access when its receiver is null. `??` supplies a fallback. The postfix null-forgiving operator, as in `nickname!`, only suppresses nullable warnings: it does not make a null value safe. This differs from Boolean negation, as in `!hasTicket`.

This project enables nullable analysis using `<Nullable>enable</Nullable>` in its project file.

## Practice

Declare `decimal? price = null`. Print `Unknown price` when it is null, then assign a value and print it.

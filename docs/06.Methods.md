# 06. Functions and Methods

[Course index](README.md) · [Previous](05.Loops.md) · [Next](07.LambdasAndExpressionBodies.md)

A function groups reusable instructions. In C#, a function declared as a member of a type is called a method. A function declared inside another function or top-level program is a local function.

```csharp
int Add(int left, int right)
{
    return left + right;
}

int total = Add(3, 4);
Console.WriteLine(total); // 7
```

`int` before `Add` is the return type. `left` and `right` are parameters: names used inside the function. `3` and `4` are arguments: values supplied by the caller. `return` sends a value back and ends that call.

Use `void` when no value comes back:

```csharp
void Greet(string name)
{
    Console.WriteLine($"Hello, {name}");
}

Greet("Alice");
```

Inside a class, a method may have an access modifier such as `public` or `private`. A `static` method is called through the type; an instance method is called through an object. We will practice both later.

Methods can be overloaded: multiple methods share a name but accept different parameter lists. A different return type alone is not enough for overloading.

## Practice

Write `decimal ApplyDiscount(decimal price, decimal discount)` that subtracts the discount. Call it with `50m` and `10m`; expect `40m`.

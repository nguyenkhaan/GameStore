# 15. Inheritance

[Course index](README.md) · [Previous](14.Interfaces.md) · [Next](16.Records.md)

Inheritance creates a more specific class from an existing one. The existing class is the base class; the new one is the derived class. Use it for an “is a” relationship.

```csharp
Game game = new OnlineGame("Arena", 4);
Console.WriteLine(game.Describe()); // Arena: up to 4 players

public class Game(string name)
{
    public string Name { get; } = name;

    public virtual string Describe()
    {
        return Name;
    }
}

public class OnlineGame(string name, int maxPlayers) : Game(name)
{
    public override string Describe()
    {
        return $"{Name}: up to {maxPlayers} players";
    }
}
```

An `OnlineGame` is a `Game`. `Game(name)` calls the base constructor. `virtual` allows a derived class to specialize a method, and `override` provides that specialization.

Even though the variable is declared as `Game`, calling its virtual method uses the `OnlineGame` implementation. This is polymorphism.

A class has at most one direct base class, but can implement multiple interfaces. Derived classes cannot directly access private base members. Use `protected` when a member should be available to derived classes. Constructors are not inherited.

An `abstract` class cannot be created directly. A `sealed` class cannot be inherited from. Learn these when your model needs them; small programs often work well with ordinary classes.

## Practice

Create an `Animal` base class with a virtual `Speak()` method. Override it in `Cat` and `Dog`, then call it through `Animal` variables.

# Pattern Matching

[Course index](README.md) · [Previous](20.CollectionInitializers.md) · [Next](22.AnonymousTypes.md)

Pattern matching checks whether a value has a certain type, value, or shape. It does not change the object.

```csharp
object person = new Person("Alice", 20);

if (person is Person { Name: "Alice" })
{
    Console.WriteLine("This is Alice");
}

public record Person(string Name, int Age);
```

A property pattern does not match `null`. Inside it, `:` introduces a pattern to test against that property's value. It is different from an object initializer, where `=` means “assign this value.”

Continuing the example above, put this test before the `Person` declaration. Patterns can check several properties at once:

```csharp
if (person is Person { Name: "Alice", Age: >= 18 })
{
    Console.WriteLine("Alice is an adult");
}
```

Use pattern matching in `if` statements or `switch` expressions when your code needs to choose behavior from the data it receives.

# Extension Methods

[Course index](README.md) · [Previous](23.StaticClasses.md) · [Next](25.ReadonlyFields.md)

An extension method lets you call a static helper method with instance-method syntax. It does not change the original type.

```csharp
bool missingName = "   ".IsBlank();
Console.WriteLine(missingName); // True

public static class StringExtensions
{
    public static bool IsBlank(this string? value)
    {
        return string.IsNullOrWhiteSpace(value);
    }
}
```

For the classic extension-method syntax used in this project:

- The containing class must be a top-level, non-generic `static` class.
- The method must be `static`.
- Its first parameter has the `this` modifier and names the type being extended.

This project uses the same idea with `WebApplication` so that `app.MapGamesEndpoints()` can be written like an instance method.

The extension's namespace must be in scope, usually through a `using` directive. You can also call it as `StringExtensions.IsBlank("   ")`. An applicable instance method takes precedence over an extension method.

Use extension methods for small helpers that naturally belong beside an existing type. Do not use them to hide complicated business logic.

## Try it

Write a `WordCount` extension method for `string` that returns the number of words in a sentence.
